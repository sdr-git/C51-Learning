##矩阵键盘
#矩阵键盘需要我们逐行（列）扫描，写一个读取按键建码的函数，我们只需要返回一个具体的按键数值，建立一个无参数的函数unsigned char MatrixKey()
#这个函数写四部分，因为矩阵键盘是又四个端口来检测行四个来检测列来确定是哪个按键，我们按照列的形式分四种情况，每一种情况需要对P1口全部高电位，之后挨个列端口赋予低电平，然后每个行需要检测四个按键的状态，通过按键的状态来输出实际的建码数值，最后return返回KeyNumber的数值
#main函数中我们让KeyNumber所返回的数值用LCD显示出来，因为在while循环中，每循环一次我们的建码值会重置为0 ，LCD将被快速刷新然后0会覆盖真实的建码值，所以需要加一个判断语句，当键码值不为0时我们在输出显示键码值
